# sravanpattabhi.github.io

Personal portfolio of Sravan Pattabhi — senior software engineer.

Hand-built as a single HTML file: no frameworks, no build step, vanilla JS and canvas.
Dark ink + terminal amber; Bricolage Grotesque / Instrument Sans / IBM Plex Mono.

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Deploy

Served by GitHub Pages from the `main` branch root. Pushing to `main` deploys.
